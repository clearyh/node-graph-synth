Core (M7):
 - lcd: graphics drivers
 - ctp: touchscreen drivers
 - clut: color lookup table
 - font: bitmap ascii font data
 - Node: generic node class and input and output classes
 - Generator: time domain signal generation nodes
 - Modulator: filter and delay nodes
 - Operator: math operation nodes
 - Hardware: tactile input and touchscreen nodes
 - InputEditor: class to represent and alter input data
 - graph: manager for the node graph

Core (M4):
 - main: driver for tactile input expansion board
